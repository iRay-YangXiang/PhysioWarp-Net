You are helping me implement a research prototype called **PhysioWarp-Net** in PyTorch.

This is an offline research project for studying temporal robustness of quantitative 4D CT perfusion pipelines. Do not implement PACS/network integration, DICOM modification, scanner integration, or deployment functionality. The project operates only on preprocessed local research arrays/NIfTI-derived tensors.

I want clean, modular, testable production-quality research code rather than a monolithic script.

# 1. Core goal

The input is a complete dynamic 4D CT perfusion sequence:

```text
X = [B, T, C, Z, H, W]
```

where:

```text
C = 1
```

and acquisition times are:

```text
times = [B, T]
```

in physical seconds.

The neural network should eventually learn:

```text
M(r)
```

a spatial soft support mask indicating where temporal manipulation is allowed/selected, and

```text
Δ(r,t)
```

a temporal displacement field measured in seconds.

The attacked image is:

```text
X'(r,t) = X(r, t + M(r) * Δ(r,t))
```

using differentiable temporal interpolation.

The network should NOT directly synthesize arbitrary CT intensities.

It should only manipulate temporal sampling coordinates.

# 2. Important implementation strategy

Implement the project in stages.

The first working milestone is Stage 1:

```text

```

Only after Stage 1 is fully tested should we add automatic support-mask prediction.

# 5. Second module: differentiable temporal sampler

This is the MOST IMPORTANT module.

Implement:

```text
warping/temporal_sampler.py
```

API:

```python
def temporal_warp(
    x: torch.Tensor,
    acquisition_times: torch.Tensor,
    delta_seconds: torch.Tensor,
    *,
    padding_mode: str = "border",
) -> torch.Tensor:
```

Inputs:

```text
x:
[B,T,C,Z,H,W]

acquisition_times:
[B,T]
or
[T]

delta_seconds:
[B,T,1,Z,H,W]
or
[B,T,Z,H,W]
```

Output:

```text
[B,T,C,Z,H,W]
```

Meaning:

For output frame t and spatial coordinate r:

```text
source_time = acquisition_times[t] + delta_seconds[t,r]
```

The signal must be interpolated along ONLY the temporal dimension.

Spatial coordinates must remain unchanged.

Requirements:

1. Fully differentiable with respect to delta_seconds.

2. Support NONUNIFORM acquisition times.

3. Perform linear interpolation initially.

4. Vectorized GPU implementation.

5. Absolutely NO Python loop over individual voxels.

6. Clamp transformed times to the valid acquisition-time range.

7. Correctly find the lower and upper neighboring acquisition frames.

For each query time q:

```text
find i such that

times[i] <= q <= times[i+1]
```

then:

```text
w = (q - times[i]) / (times[i+1] - times[i])

value(q)
=
(1-w) * X[i]
+
w * X[i+1]
```

Use torch.searchsorted if practical.

Take care that batched nonuniform acquisition times may differ between cases.

Avoid division by zero using a small epsilon.
